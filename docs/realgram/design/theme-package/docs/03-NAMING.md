# RealGram — Naming Guide (Shahnameh / Ancient Persia)

The goal: names that feel rooted in the Shahnameh and old Persia, but stay
short, pronounceable across languages, and — like **Zar** and **REAL** already
are — usable *untranslated* as brand terms. Each entry gives the recommended
name, the meaning, and a fallback in case a plain-English label is needed.

Keep the currency spine intact: **Zar** (forged soft currency) → **REAL** (hard
token on TON). Don't rename those.

---

## Currencies & economy (keep / extend)

| Concept | Name | Meaning / rationale |
|--------|------|--------------------|
| Soft currency (tapped/mined) | **Zar** | Persian *zar* = gold. Keep. |
| Hard token (TON) | **REAL** | Existing brand token. Keep. |
| Premium gem | **Gohar** (گوهر) | "gem / jewel". Replaces generic "Gems". |
| Prestige/soul stat | **Farr** (فرّ) | *farr* = divine royal glory in the Shahnameh. Already fits — keep. |
| XP | **Kherad** (خرد) | "wisdom/intellect" — what you gain by *learning* the epic. Optional flavour for XP. |

## Core RealGram sections (bottom nav)

| Screen | Recommended | Meaning | Safe fallback |
|--------|-------------|---------|---------------|
| Home / tap | **The Anvil** (Sandan · سندان) | where Zar is forged | "Home" |
| Wallet | **Ganj** (گنج) | "treasure/hoard" — famous in Persian verse (*ganj-e shāyegān*) | "Wallet" |
| Shop | **Ganj Bazaar** | the treasure market | "Shop" |
| VPN / servers | **Freedom** / **Rah** (راه, "the path/road") | keep "Freedom" as the tab; "Rah" as flavour | "Servers" |
| Referral system | **Sepah** (سپاه, "army/host") or **Warrior Earnings** | your growing host earns you 10% forever | "Referrals" |
| Clan | **Clan** / **Tabar** (تبار, "lineage/clan") | keep "Clan", "Tabar" as flavour | "Clan" |
| Profile | **Shah** card / "Your Crown" | king/queen identity (King/Queen already in onboarding) | "Profile" |

Note on **Ganj**: localise the *tagline*, not the word — keep "Ganj" as the brand
name in every language, exactly like "Zar":
- EN: "Ganj — your treasure"
- FA: «گنج — خزانهٔ تو»
- ZH: "Ganj — 你的宝藏"
- RU: "Ganj — ваша сокровищница"
